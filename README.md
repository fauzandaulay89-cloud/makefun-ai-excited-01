A program that draws, pixel by pixel, a colossal luminous jellyfish drifting over a tiny neon coastal town at night — fully procedural art made to excite make.fun's AI judge. One glowing giant, a miniature lit-up town below it for scale, ribbons of coloured light sweeping down in a diagonal current: a jolt of awe that still reads at 300 pixels wide.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
